# Capíva — Landing Page

Landing page do Capíva, um projeto pessoal que nasceu da ideia de organizar minha vida financeira em um aplicativo.

## Sobre

Esta é a primeira etapa do projeto. Comecei pela landing page para praticar HTML, CSS e JavaScript antes de avançar para as funcionalidades financeiras.

## O que já foi feito

- estrutura da página com HTML;
- identidade visual com CSS;
- apresentação do objetivo do projeto;
- troca entre tema claro e escuro com JavaScript.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

Abra o arquivo `index.html` no navegador ou utilize uma extensão de servidor local no editor.
